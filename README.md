# Ali Asghar — Portfolio V3

Responsive, dark-themed React portfolio built with Vite, Tailwind CSS, and Motion.

## Run locally (Windows PowerShell)

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL reported by Vite. Stop with Ctrl+C.

## Build

```powershell
npm.cmd run build
```
